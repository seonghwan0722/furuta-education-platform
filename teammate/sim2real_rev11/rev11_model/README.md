- CAD에는 진자 다리가 −y 방향으로 **수평으로 눕혀** 그려져 있어서, 피벗 축 기준 +90° 돌려 **각도 0 = 아래로 매달림**, π = 도립으로 맞췄습니다(키프레임 `down`, `up`).
- Arm 방향은 +x(0°)입니다. 회전 반경(모터 축 → 진자 다리)은 약 80 mm.
- 질량·무게중심·관성은 STEP 솔리드 부피 × 재질 밀도(PLA 1.24, 강 7.85, NdFeB 7.5 g/cm³ 등)로 계산했습니다. 부품별 값은 `massprops.json`.
- 충돌 끔, 시각용 메시는 재질별로 묶음(약 12만 삼각형), 1 ms 스텝, RK4.

## 실기와 맞추기 전에 정해야 하는 값 (가정값)
1. **모터 반사관성 `armature` = 0, 그리고 모터 출력부 질량 없음** — 이 STEP은 RMD-X6가 한 덩어리라 회전하는 출력 플랜지를 분리할 수 없어 base에 넣었습니다. 로터 관성 × 20²와 출력부를 armature로 넣어야 합니다.
2. Arm 쿨롱 마찰 0.012 N·m·감쇠 1e-4, 진자 마찰 2e-4 N·m·감쇠 1e-5 — 추정치. 이 버전은 688ZZ 2개에 출력물 축이 직접 물려 있어 실제 마찰이 더 클 수 있습니다.
3. 출력물 밀도 1.24 g/cm³: 진자(인필 100 %)는 맞고, 허브·홀더·하우징은 실제 인필에 따라 가벼워질 수 있습니다.
4. 688ZZ는 카탈로그 질량 3.6 g으로 보정.
5. AS5600 12비트 양자화, 통신 지연은 학습 환경 래퍼에서 넣으세요. 토크 한계 ±1 N·m는 학습 안전용 클램프.
6. **볼트 추 M6×30은 11-02 버니어 실측으로 교체**: 머리 Ø13.3 × 높이 5.1, 머리 아래 길이 30.0, 나사 외경 5.8. CAD 볼트는 머리 높이 약 3.3, 길이 29로 9.2 g이었고, 실측 형상(머리 윗모서리 R3 돔 가정, 강 7.85)으로 11.2 g이 됩니다. 머리 돔 모양에 따라 10.8~11.8 g 범위라, 저울로 한 번 재서 `tools/replace_bolt.py`의 형상 또는 밀도를 맞추면 확정됩니다. (`tools/replace_bolt.py` → `massprops.py` → `build_mjcf.py` 순서로 재생성)
