# RL 블록 실험실 (Furuta 진자 강화학습 교육용)

고등학생이 **코드 없이 Simulink처럼 블록을 이어서** 보상 함수와 학습 설정을 바꾸고,
MuJoCo 시뮬레이션에서 PPO로 학습시킨 뒤, 학습된 정책을 **라즈베리파이**로 옮기는 프로그램입니다.
인터넷 없이 동작하는 로컬 웹 앱입니다 (Python 서버 + 브라우저 화면).

```
[PPO 에이전트] ──모터 명령──▶ [퓨루타 진자 (MuJoCo)] ──센서값──▶ [계산 블록] ──▶ [보상 항] … (합계 = 점수)
      ▲                              │                                        └─▶ [판 끝내기]
      └────────── 관측값 묶음 ───────┘                                         └─▶ [스코프]
[PPO 에이전트] ──학습된 정책──▶ [라즈베리파이로]  →  policy.npz + pi_policy.py (numpy만 필요)
```

## 1. 설치 (수업용 PC, Windows/Mac/Linux)

Python 3.10 이상에서:

```bash
pip install -r requirements.txt
```

## 2. 실행

```bash
python server.py
```

브라우저가 자동으로 `http://localhost:8770` 을 엽니다. (Windows는 `실행.bat` 더블클릭)

## 3. 수업 흐름

1. **예제 불러오기**: 위쪽 목록에서 레벨을 고르고 `예제 불러오기`.
2. **블록 바꾸기**: 왼쪽 목록에서 블록을 끌어 놓고, 오른쪽 점(●)을 끌어서 다른 블록 왼쪽 점에 놓으면 선이 이어집니다.
   블록을 누르면 오른쪽 창에서 값(가중치, 진자 무게, 학습률 …)을 바꿉니다. 지우기는 `Delete`.
3. **▶ 학습 시작**: 실험 이름을 적고 누르면 아래 `학습 결과` 탭에 점수 그래프가 실시간으로 그려집니다.
   `■ 멈추기`를 누르면 그때까지 배운 정책이 저장됩니다.
4. **🧪 시험 주행**: 학습된 정책으로 진자를 움직여 애니메이션과 스코프 그래프로 확인합니다.
   지금 화면의 진자 설정으로 돌리므로, 진자 무게나 모터 토크를 바꾸고 다시 시험 주행하면 **정책이 얼마나 버티는지** 볼 수 있습니다.
   `🎥 3D 뷰어`는 서버를 실행한 컴퓨터에 MuJoCo 3D 창을 띄웁니다.
5. **비교**: 학습 기록 표에서 여러 실험에 체크하면 곡선이 겹쳐 그려집니다.
   보상 설계가 다르면 점수끼리는 비교할 수 없으므로, 공통 성적표인 **똑바로 선 시간 비율(위에서 ±20° 안)**로 비교합니다.
6. **🍓 라즈베리파이**: 정책을 골라 `내보내기` → zip을 받아 라즈베리파이로 옮깁니다 (아래 5번).

## 4. 예제 (레벨)

| 예제 | 내용 | 확인한 결과 (CAD 모델, 이 PC 기준) |
|---|---|---|
| 레벨 0 | 진자 + 에이전트만. 보상을 직접 만들기 | 보상 항이 없으면 학습 시작이 막힘 |
| 레벨 1 | 높이 h + 모터 힘 벌점 | 20만 스텝(약 3~4분)부터 한 판의 약 90%를 똑바로 서 있음 |
| 레벨 2 | + 속도 벌점, 서 있기 보너스, 팔 1바퀴 넘으면 판 끝내기 | 25만 스텝부터 약 88~89% |
| 토론 | 원래 `env.py` 보상 그대로 | 40만 스텝까지 0% (팔이 가벼워 팔 속도 벌점이 너무 큼 → 가중치를 고쳐 보는 토론 거리) |
| 레벨 3 | 레벨 2 + 도메인 랜덤화 (Sim-to-Real용) | 35만 스텝부터 약 89~90% |

**Sim-to-Real 토론용 결과**: 레벨 1로 학습한 정책은 진자를 130%로 무겁게 하면 선 시간이 94% → 13%로 무너졌지만,
레벨 3(랜덤화)으로 학습한 정책은 130%에서 95%, 160%에서도 94%를 유지했습니다 (10초 시험 주행 5회).
수업에서 '진자 무게 배율'을 바꿔 시험 주행해 보면 같은 결과를 직접 볼 수 있습니다.

`runs/` 에는 확인용으로 학습해 둔 `레벨1-기본` 기록(30만 스텝)이 들어 있어서, 설치 후 바로 시험 주행·내보내기를 해 볼 수 있습니다.

## 5. 라즈베리파이로 옮기기

내보낸 zip 안에는 `policy.npz`(신경망 가중치), `policy_meta.json`(관측 순서·제어 주기·최대 토크·확인용 값), `pi_policy.py` 가 있습니다.
라즈베리파이에는 **numpy만** 있으면 됩니다 (PyTorch·MuJoCo 불필요).

```bash
sudo apt install python3-numpy
python3 pi_policy.py --test      # 시뮬레이션과 같은 답이 나오는지 (기계 없이)
python3 pi_policy.py --bench     # 1회 계산 시간 (제어 주기 10 ms 보다 훨씬 짧아야 함)
python3 pi_policy.py --run --port /dev/ttyACM0
```

`--run` 의 `SerialMotorBridge` 는 **예시 통신 형식**입니다 (Pi→MCU `T<토크>\n`, MCU→Pi `<팔각>,<진자각>\n`).
FOC 드라이버 MCU 펌웨어가 정해지면 `read_angles()` / `send_torque()` 두 함수만 맞게 고치면 됩니다.
시뮬레이션과 약속을 꼭 맞춰야 합니다: 진자각은 **아래로 매달림 = 0, 위 = ±π**, 모터 +방향과 팔 각도 +방향이 MuJoCo 모델과 같아야 합니다.

## 6. 파일 구조

```
rl_blocklab/
├── server.py        로컬 웹 서버 (http://localhost:8770)
├── blocks.py        블록 종류 정의 (블록 추가는 여기 + graph.py)
├── graph.py         블록 그래프 → 학습 설정 / 매 스텝 보상 계산
├── furuta_env.py    Gymnasium 환경 (관측·행동은 원래 env.py 와 동일)
├── trainer.py       PPO 학습(Stable-Baselines3), 시험 주행, 라즈베리파이 내보내기
├── templates.py     수업용 예제 (레벨 0~3)
├── viewer_run.py    MuJoCo 3D 뷰어
├── models/          furuta_cad.xml (= Capstone1/test/test_sim.xml 복사본) + meshes, furuta_rod.xml
├── pi/pi_policy.py  라즈베리파이 실행 스크립트 (내보낼 때 복사됨)
├── static/          화면 (index.html, style.css, app.js — 외부 라이브러리 없음)
└── runs/            학습 기록 (실험마다 graph.json, model.zip, curve.json, pi/ …)
```

CAD를 다시 내보내면 `models/furuta_cad.xml` 과 `models/meshes/` 를 새 파일로 바꾸면 됩니다
(조인트 순서: 0번 = 팔, 1번 = 진자, 진자 qpos=0 이 아래로 매달린 자세, 모터 1개).
