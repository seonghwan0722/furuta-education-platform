## 원고와 Canva 교정본의 차이

[lesson_briefs.json](lesson_briefs.json)은 세 수업의 초기 생성 원고입니다. `briefs` 배열에 슬라이드별 내용, 시각자료 지시, 교사용 설명과 출처가 들어 있습니다. 완성 슬라이드의 내보내기 파일이나 앱 실행 파일은 아닙니다.

로컬 상태 기록상 60장 미리보기와 앱 소스를 검토하고, 아래 페이지를 교정한 뒤 미리보기를 확인했습니다. **교정본의 Canva 영구 저장은 대기 상태**입니다. 따라서 링크가 최신 교정 내용을 보여 준다고 가정해서는 안 됩니다. GitHub에 원고를 올리는 작업은 Canva 편집의 영구 저장과 별개입니다.

| 수업 | 교정한 페이지 |
| --- | --- |
| 1 | 7, 14, 18, 19 |
| 2 | 2, 3, 4, 17, 18, 19 |
| 3 | 3, 18 |

`lesson_briefs.json`은 교정 후 다시 쓴 원고가 아니므로, 이를 그대로 재생성하면 교정 전 설명이나 그림 지시가 다시 나타날 수 있습니다. 특히 다음 사항을 최신 앱과 대조해야 합니다.

- 활동 번호와 이동 경로: 활동 0은 배경지식이며, 본 수업 흐름은 1 살펴보기 → 2 점수 규칙 만들기 → 3 가르치고 시험하기입니다.
- 길찾기 경로: 앱의 최고 보상 경로는 초록 실선, 최근 학습 경로는 보라 점선입니다. 초기 원고의 청록·주황 지시는 현재 앱 색상과 다릅니다. ‘최고’는 관측한 학습 기록 중 최고이며 이론적인 최적 경로가 아닙니다. 경로의 보상 합과 칸의 할인 누적보상 추정치도 구분합니다.
- 진자 도식: 아래 자세는 `α = 0`, 직립은 `α = π`입니다. 기호·속도 부호·그림의 방향이 일치해야 하며, `φ = wrap(α − π)`인 직립 오차와 진자각을 혼용하지 않습니다.
- 학습 방식: 길찾기는 Q-learning, 따라 하기는 SAC 사전 정책 실행·비교, 자유 규칙 학습은 CEM입니다. Pi에서는 전송한 정책을 추론합니다. 이를 모두 PPO 학습이라고 설명하지 않습니다.
- 평가와 저장: 현재 40조건 선별은 시뮬레이션 평가이며 실물 성공률이 아닙니다. `.pendulum`에는 활동 0의 Q표·경로와 제어 실험실 기록, 연결 정보·보정값·구동 승인이 포함되지 않습니다. 불러오기만으로 모터가 작동하지 않습니다.
- 제어 실험실: ‘실물 보정’ 환경도 PC 시뮬레이션입니다. 새 USB 연결·자동 스윙업·PID/LQR/LMPC 실물 경로는 소스 구현 단계이며 실물 성공이 검증되지 않았습니다.

Canva 임시 트랜잭션, 서명된 미리보기 URL, 원본 참고 디자인 내용과 도구 응답은 공개 원고에 포함하지 않았습니다.

## 수업에서의 사용

학생은 ‘예상 → 한 조건 변경 → 동일 조건 실험 → 관찰 → 설명’ 순서로 활동합니다. 활동지와 비교표에는 학생이 관찰한 값을 직접 기록하며, 설명용 그래프나 계산 예시를 측정 결과로 제시하지 않습니다. PID·LQR·LMPC는 같은 비선형 진자에서 비교하고, LQR 등의 게인 설계에 사용하는 직립 근처 선형 모델과 실제 실험 환경을 구분합니다.

실제 키트 부분은 교사의 준비·시연 절차를 설명하는 자료입니다. 새 경로의 설치·전원·센서·구동 확인과 실물 검증을 마치기 전에는 수업 자료 자체를 검증 완료된 운용 매뉴얼로 사용하지 않습니다. 이 자료 제작·교정 작업에서 앱·Pi·모터 시험을 새로 수행하지 않았습니다.

실물 사진이 필요한 곳은 촬영할 대상을 적은 빈칸으로 남겼습니다. 완성 장치와 배선 사진, 최신 앱 화면을 넣은 뒤 안내 문구를 지우고, 교정본을 영구 저장한 다음 PDF/PPTX 내보내기와 전체 페이지 확인을 진행하면 됩니다.
