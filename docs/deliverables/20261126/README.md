## 후속 Canva 수정 상태

[10분 최종 발표 Canva 디자인](https://www.canva.com/d/ll0dMdPaRIccGzD)

로컬 상태 기록상 후속 수정은 검토한 초안이며 **Canva 영구 저장 대기 상태**입니다. GitHub 업로드와 Canva 편집 내용의 영구 저장은 별개입니다. 링크를 열었을 때 후속 교정이 모두 보인다고 가정하지 말고, 사용 전에 후속 대본과 대조해야 합니다. 이 저장소에는 Canva 임시 트랜잭션, 서명된 미리보기 URL과 참고 디자인 응답 원본을 포함하지 않았습니다.

후속 교정의 핵심은 다음과 같습니다.

- 활동 0 배경지식·길찾기, 보상 블록 개선, `.pendulum` 저장·불러오기를 발표에 추가했습니다.
- 제어 실험실의 자동 스윙업과 Pi 제어 코드 확장을 설명하고, 실제 검증 범위를 분리했습니다.
- 기존 SSH 연결 실물 기록과 새 USB 연결·PID/LQR/LMPC 경로를 구분했습니다.
- 팔·진자의 식별 방법, 실물 시험의 제어기 버전, 과거 CEM 32조건 평가와 현재 앱의 40조건 선별을 구분했습니다.
- 사진 빈칸을 유지하고, 600초 분량의 대본과 근거 부록을 갱신했습니다.

발표에 남아 있는 앱 화면은 이전 UI라는 표시를 유지해야 합니다. 최근 소스 변경이 과거 설치 파일에도 포함되었다고 설명하면 안 됩니다. 이 발표 수정 작업에서는 앱·Pi·모터 시험을 새로 수행하지 않았습니다.

## 검증 범위와 사용 전 확인

기존 MATLAB 계열 실물 시험과 팀원 정책의 50 Hz·1.2 A 실물 시험은 각각 기록된 조건과 버전의 결과입니다. 이 결과를 새 USB 제어 경로의 성공 증거로 사용하지 않습니다.

새 USB 연결과 ‘아래 자세에서 자동 스윙업 후 PID·LQR·LMPC로 전환’ 경로는 **소스 구현 단계이며 Pi 설치와 실물 검증이 완료되지 않았습니다**. 시뮬레이션 결과와 실제 키트 결과, 학습과 정책 추론을 구분해 발표해야 합니다. 최신 기능과 배포 상태는 [앱 문서](../../../pendulum_studio/README.md) 및 [실제 키트 제어 문서](../../../pendulum_studio/kit/CLASSICAL_CONTROL.md)를 함께 확인하세요.

발표·제출 전에 후속 대본의 교정을 로컬 산출물에 반영하고, 지정된 실물 사진을 넣은 뒤 사진 안내 문구를 지워야 합니다. 시험 사진에는 대응 로그명과 시각을 함께 표시하고, 글꼴·페이지 나눔·출력 크기는 최종 편집본에서 확인하세요.
