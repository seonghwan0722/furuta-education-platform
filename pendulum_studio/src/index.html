USB 케이블로 키트를 연결한 뒤 아래 버튼을 누르세요.

키트는 스스로 멈춥니다: 너무 빨리 돌 때, 진자가 계속 돌 때, 연결이 끊겼을 때. 이 안전 동작은 끌 수 없습니다.

상단의 ‘활동 순서’를 따라가면 됩니다. 오른쪽 탭은 지금 활동에 필요한 도구를 여는 곳이에요.

  1. 0

    배경지식

    인공지능이 배우는 방법과 강화학습의 말을 알아봅니다. 길찾기·밴딧 예제로 경험과 보상을 연결하고, 수학적 모델링으로 움직임을 설명해 보세요.

  2. 1

    살펴보기

    진자와 센서를 살펴보고 미리 배운 에이전트가 어떻게 움직이는지 관찰합니다. 상태·행동·보상·가치가 무엇을 뜻하는지 연결해 보세요.

  3. 2

    점수 규칙 만들기

    무엇을 잘한 행동으로 볼지 정합니다. ‘따라 하기’에서 시작하거나 ‘자유롭게 만들기’에서 점수 블록을 조립하세요. 결과가 어떻게 달라질지 먼저 적어 봅니다.

  4. 3

    가르치고 시험하기

    도움말을 닫고 ‘시작하기’를 누르면 현재 규칙과 조건에 맞춰 학습·시험합니다. 결과 기록을 눌러 비교 대상을 고르고, 그래프에서 움직임과 힘의 차이를 확인하세요.

같은 조건에서 비교하면 이유를 찾기 쉬워요.

한 번에 한 가지 점수 규칙만 바꾸고, 바꾸기 전 예상과 실제 결과를 함께 적어 보세요.

점수 규칙

블록은 ‘어떤 행동에 점수를 줄지’ 표현하는 도구예요.

오른쪽 ‘블록’ 탭에서 조립하고, ‘예시 규칙’ 탭에서 출발점을 찾아보세요.

블록을 가져와 연결하기

검색이나 범주에서 블록을 찾아 끌어옵니다. 드래그가 어렵다면 넣을 숫자·조건 칸 또는 ‘이 안쪽에 추가’를 선택한 뒤 꾸러미의 ‘추가’를 누르세요. ‘점수 끝 선택’과 ‘시작 끝 선택’도 사용할 수 있습니다.

뜻이 궁금한 블록 누르기

블록을 누르면 왼쪽 아래 ‘블록 도움말’에 설명이 나옵니다. 블록 이름과 설명을 읽고 어떤 상태에 점수를 주는지 확인하세요.

지우거나 되돌리기

휴지통에 끌면 이동 중인 묶음이 삭제됩니다. ‘선택 삭제’는 선택한 블록과 그 안쪽만 지웁니다. 칸을 교체하면 기존 블록은 조립소 아래에 보관합니다. ‘되돌리기’로 복구하고, 이동 중 Esc로 취소하세요.

Ctrl + Z 되돌리기 · Ctrl + Y 다시 실행 · 블록 선택 후 Ctrl + D 복사

예시에서 시작하기

‘예시 규칙’에서 설명을 읽고 ‘이 규칙 불러오기’를 선택합니다. 불러온 규칙을 그대로 관찰한 뒤 한 가지 값만 바꿔 비교해 보세요.

문제 표시 읽기

빈 조건, 잘못된 숫자, 0으로 나누기, 지원하지 않는 시작 순서는 ‘수정 필요’로 알려 줍니다. 목록을 누르면 문제 블록으로 이동합니다. 입력을 끝내려면 Enter, 취소하려면 Esc를 누르세요. ‘참고’는 보상 의도나 단위를 생각해 보라는 안내이며 학습 성공을 보장하는 판정은 아닙니다.

시작 묶음은 조건 → 학습 → 시험 순서로 만듭니다. 같은 규칙으로 이미 배운 정책은 다시 사용합니다. 따로 놓인 블록은 실행되지 않으며, 미완성 규칙도 숫자 입력을 마치면 수업 파일로 저장할 수 있습니다.

규칙을 바꾸면 배우는 목표도 달라져요.

제어 실험실

같은 진자에 대해 사람이 정한 제어 규칙을 비교하는 PC 시뮬레이션입니다. PID는 지금·누적·변화에 반응하고, LQR은 오차와 힘의 비용을 절충하며, LMPC는 미래를 예측해 매번 다시 계획합니다.

여는 곳: 상단 메뉴 → 제어 실험실

키트 맞추기

이 키트의 팔 마찰·관성, 진자 흔들림 주기, 진자 영점을 잽니다. 키트마다 조금씩 다른 값을 알아 두는 단계입니다.

약 40초 동안 모터가 움직입니다: 팔이 90°씩 세 번 돌고, 세게 돌았다 멈추기를 여섯 번 한 뒤, 잠긴 채 진자가 흔들립니다. 키트 주변을 비우고 손을 떼 주세요. 받침 수평은 이것과 따로 실행할 때마다 잽니다.

배운 정책을 진자 키트로

정책을 Pi에 보내면 Pi 안에서 실행하고, 움직임과 결과를 이 화면으로 받습니다.

  1. 1 · 연결아래에서 Pi의 포트를 선택
  2. 2 · 수평과 준비받침 수평 조정 → 키트 점검
  3. 3 · 직접 시작시뮬레이션 확인 → 실제 키트 시작

포트가 보이지 않거나 연결이 안 되나요?
  • Pi에서 키트 대기 프로그램이 실행 중이어야 합니다. COM 포트가 있다고 Pi 연결이 확인된 것은 아닙니다.
  • Pi 5의 USB-C 직결은 USB 직렬 장치 모드 설정과 PC 포트의 전원 출력 확인이 필요합니다. 일반 USB-A 단자끼리 케이블로 잇는 방식은 지원하지 않습니다.
  • 같은 케이블로 Pi 전원도 공급한다면 케이블을 빼지 말고 ‘정지하기’를 먼저 누르세요. Pi 전원이 끊기면 앱의 정지 명령도 전달되지 않습니다.
  • USB-시리얼 어댑터를 쓰면 Pi의 UART 또는 Pi 쪽 어댑터와 배선을 확인하세요. 충전 전용 케이블과 Bluetooth 포트는 구분해야 합니다.
  • 115200 bps · 규약 v2. 다른 직렬 터미널을 닫고 ‘다시 찾기’를 누르세요.

연결 후 IMU 각도 확인은 모터를 움직이지 않습니다. ‘키트 맞추기’와 ‘실제 키트 → 시작하기’를 누르면 팔이 움직이며, 정책 실행 전에도 기존 수평·영점 측정을 위해 회전합니다.
