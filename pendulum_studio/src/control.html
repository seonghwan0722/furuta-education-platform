명령을 정하는 방법현재·누적·변화율의 합에 팔 피드백 추가모델·비용으로 구한 K와 현재 상태의 곱현재 상태에서 제한 안의 미래 입력 계획 계산
설정에서 바꾸는 것P·I·D 기준 게인의 배율상태와 힘의 중요도 Q·RQ·R, 예측 길이 N
힘의 상한합산한 명령을 제한, I 누적 조절 가능계산한 명령을 상한에서 제한계획을 계산할 때부터 입력 제한 포함
그래프에서 볼 것흔들림, 누적, 상한 도달오차와 힘 사용의 절충예측, 상한, 재계획과 실제 응답

세 방법 모두 다음 측정값을 받아 명령을 다시 계산합니다. 결과는 게인·시작 상태·마찰·상한에 따라 달라지며, 어떤 방법이 항상 우수하다고 정해져 있지는 않습니다.

공통 기호와 실험 조건 다시 보기

상태는 [팔 각도, 진자 직립 오차, 팔 각속도, 진자 각속도]입니다. 게인 계산은 직립점에서 선형화하고, 실험은 기존 비선형 Furuta 모델을 사용합니다. Q와 R은 게인을 계산하는 점수 기준이며 신경망을 학습하지 않습니다.

PID에는 팔의 위치·속도 피드백을 함께 씁니다. P·D 기본값은 기준 LQR 게인을 출발점으로 정했으므로 기본 PD와 LQR의 결과가 같을 수 있습니다. 슬라이더는 이 기준의 배율입니다.

LMPC는 입력 상한을 포함한 4상태 QP를 매 주기 풉니다. 종단 비용은 LQR 해입니다. 입력 제한이 작동하지 않으면 LQR과 같은 결과가 나올 수 있습니다. 각도·속도에는 QP 제약을 두지 않습니다.

모터 명령과 힘 RMS는 비율입니다. 1의 기준 토크는 2.52 N·m이며, 보정 모델의 실제 토크에는 추가 제한이 적용됩니다.

시뮬레이션은 직립 근처 또는 아래 자세에서 시작하는 10초 실험을 선택할 수 있습니다. 실제 키트는 수평 측정 후 자동 스윙업과 선택한 제어기의 직립 유지를 수행합니다. 실물의 스윙업 설정과 게인은 시험 전 후보이며, 시뮬레이션 통과가 실물 성공을 보장하지 않습니다. 기울기·속도·계산 실패 등의 종료 사유는 실험 기록에 남깁니다.
