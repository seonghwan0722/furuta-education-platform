# PID·LQR·LMPC 제어 실험실 확장

2026-11-26 / 로컬 확장판 `0.3.0-classroom.2` / 기반 커밋 `5cf850e`

## 실행

`app/dist-ux/PendulumStudio-Classroom-Setup-0.3.0-classroom.2.exe`는 이전 Windows 설치 파일이다. **이번 USB·실물 제어 확장은 이 설치 파일에 다시 패키징하지 않았다.** 최신 기능은 `app`에서 `npm.cmd start`로 실행한다. 기존 배포 파일은 보존했다.

앱 상단 **제어 실험실** → PID / LQR / LMPC → 예상 작성 → 설정 변경 → **시작하기** 또는 **세 방법 비교** 순서로 사용한다. 실행 중인 강화학습 실험을 먼저 종료하되, 연결은 유지해도 된다. **실제 키트**를 고르면 같은 Pi 연결로 설정을 보내고 Pi에서 제어한다. 실물의 세 방법 자동 연속 비교는 하지 않는다. 사용자가 방법을 골라 각각 시작한다. [실물 제어 안내](../kit/CLASSICAL_CONTROL.md)

소스 실행은 `app`에서 `npm ci` 후 `npm start`, 계산 검사는 `npm test`다. 공식 GitHub 릴리스에 업로드하거나 원격 저장소에 푸시하지 않았다.

## UI·UX 개선판

UI·UX 담당 에이전트가 정보 구조와 시각 디자인을 정리하고, 주 작업자가 화면 동작과 검증을 통합했다. 제어 계산과 물리 모델, 기존 SAC 학습·키트 경로는 그대로 사용한다.

- 설정과 결과를 두 영역으로 나누고, 고급 조건은 펼쳐서 조정한다.
- 실행·정지·세 방법 비교는 하단에 고정한다.
- 결과와 실험 노트 탭으로 관찰·예상·설명을 이어 간다. 탭은 방향키·Home·End로 이동할 수 있다.
- 다음 실험의 설정과 마지막 실행의 조건을 따로 표시한다.
- 기록 선택색과 그래프 범례를 일치시키며, 완료/중단과 실행 시간을 함께 보여 준다.
- 기존 배포 폴더 `app/dist`는 유지하고 개선판은 `app/dist-ux`에 별도로 저장한다.

디자인 결정은 `CONTROL_LAB_UX.md`, 화면 확인 자료는 `control_validation/ux/`에 보관한다.

## 학습 기능

| 방법 | 조정과 관찰 | 계산 |
|---|---|---|
| PID | P만 / PD / PID, 항별 힘, 적분 누적 제한 | 진자 오차 PID + 팔 위치·속도 피드백 |
| LQR | 진자·팔 중요도 Q, 힘 비용 R, 오차와 힘 RMS | 직립점 이산 선형화 → Riccati 방정식 → 상태 피드백 |
| LMPC | 예측 구간 5~40칸, 입력 상한, 매 주기 미래 궤적 | 선형 예측 + 종단 LQR 비용 + 입력 제한 QP, 첫 입력만 실행 |

공통 기능은 ±30° 시작각, 2초 시점 각속도 외란, 10초 실험, 1배/4배 재생, 3기록 그래프 비교, CSV 내보내기, 예상·관찰·설명 노트, 개념 확인 문제다. 노트는 로컬 저장되고 JSON으로 제출할 수 있다. 실행 기록은 최대 12개이며 앱을 닫기 전에 내려받는다.

수업 제안(약 30분): PID 8분 → LQR 7분 → LMPC 8분 → 같은 조건 비교·설명 7분. 결과를 예상하고 한 변수만 변경한다. 실패한 실행의 평균 오차는 종료 전 구간만 계산하므로, 완료 여부와 실행 시간도 함께 본다.

## 모델과 단위

기존 `PS.Furuta`의 기구·질량행렬을 재사용한다. 기존 강화학습 환경과 정책 파일은 수정하지 않았다.

- **원리 보기**: 같은 비선형 기구에 쿨롱 마찰·측정 양자화·지연을 끄고, 팔 점성 0.02와 연속 토크·정확한 상태를 사용한다. 실제 모터를 재현한다는 뜻이 아니다.
- **실물 보정 모델**: 기존 앱의 `Furuta.step()`을 그대로 호출한다. 관성 J=0.0245, 쿨롱 Fp/Fm=0.69/0.68, 점성 b=0.17, 결합 배율 0.87, 토크 배율 0.95, 2 ms 적용 지연과 모터 관측의 주기 지연 등을 유지한다.
- 상태: `[팔 각도, 진자 직립 오차, 팔 각속도, 진자 각속도]` (rad, rad/s). 화면의 각도는 °다. 기존 모델의 진자 각도 π가 직립이다.
- 힘 그래프와 RMS는 무차원 명령 `u`다. 기준 토크는 `u × 2.52 N·m`이다. 보정 모델에서는 속도·제동 제한, 0.01 A 양자화, 토크 배율 적용 뒤 실제 토크가 달라진다. CSV의 `actual_torque_Nm`으로 구분한다.
- LQR·LMPC의 설계 모델은 원리 보기의 직립 선형화이며, 실험 플랜트는 비선형이다. 보정 환경에서는 모델 불일치의 영향도 관찰한다.
- 기본 PID의 P·D와 팔 피드백은 기준 LQR 게인을 출발점으로 잡았다. 기본 I=0이면 LQR과 같을 수 있다. LMPC도 입력 제약이 비활성이고 LQR 종단 비용을 쓰면 LQR과 같을 수 있다. 이 관계를 화면에서 설명한다.
- LMPC는 입력 제약만 포함한다. 각도·속도 제한은 QP 제약이 아닌 실험 종료 조건이다. 균형 유지 중 60° 이탈 또는 기존 속도 한계에서 종료한다. 별도의 아래 자세 시작 모드에서는 보정 비선형 모델로 에너지 스윙업→선택 제어기 전환을 연습한다.
- QP는 입력 상한을 지키는 active-set 방법과 자유 변수 Cholesky 풀이를 사용한다. 기존 직립 근처 수업 시뮬레이션은 미수렴 시 실행 가능한 근사해와 잔차를 표시한다. **새 스윙업 시뮬레이션 및 실물 경로는 미수렴을 종료 사유로 처리한다.** 실물은 계산 시간 초과도 정지 사유다.

## 검증 범위

**아래 목록은 기존 시뮬레이션 확장판의 과거 검증 기록이다.** 이번 자동 스윙업·실물 PID/LQR/LMPC·새 USB 프로토콜 변경에는 적용되지 않는다. 이번 작업은 사용자 요청에 따라 소스 검토와 diff 점검만 했으며 앱, 시뮬레이션, 자동 테스트, Pi 설치, 모터를 실행하지 않았다. Python–JavaScript 수치 대조, Pi 계산 시간과 실제 포착·유지는 미확인이다.

- 계산 검사 9종: Riccati 잔차, Q/R 변경, 독립 비용 계산과 QP 비교, KKT 조건, 비제약 MPC–LQR 일치, 적분과 anti-windup, ±5° 비선형 직립, 의도적 실패·종료 조건, 보정 플랜트와 원본 토크 경로 일치.
- 브라우저 검사: 세 방법 실행·기록, 정지, 퀴즈, CSV, 노트 재진입 보존, 기존 SAC 재생, 1440/1100/760 px 화면.
- Windows 패키징 실행 파일을 숨김 실행해 세 제어기의 비교 및 기존 SAC 재생이 동작함을 확인했다. 설치 마법사의 실제 설치·삭제 및 실물 장치 시험은 이번 검증 범위에 포함하지 않는다.
- LMPC 수업 조건은 시작각 10°·상한 40%로 잡았다. N=5와 N=30 모두 10초 완료했고 평균 오차는 각각 0.555°와 0.531°다. 상한을 20%로 낮추면 둘 다 60° 이탈로 종료한다. 34개 기록을 `control_validation/experiments.json`에 보관했다. 이 결과는 PC 시뮬레이션이며 예측 구간이 길수록 항상 우수하다는 뜻이 아니다.
- 교육적 효과는 학생 시험 전이며, 게인은 실물 배포용으로 검증하지 않았다.
