# 학생용 블록 구성 보강 — 2026-11-26

## 목표와 범위

숫자와 조건의 차이, 경계값, 단위, 부호, 중첩된 규칙을 수업에서 직접 표현할 수 있도록 블록과 편집 흐름을 보강한다. 예상 가능한 주요 학습 상황을 다루며 모든 사용 상황이나 학습 성공을 보장한다고 표현하지 않는다.

## 수업 중 편집 흐름

| 상황 | 현재 UI와 동작 |
|---|---|
| 원하는 블록을 찾기 어려움 | 꾸러미 검색은 모든 범주에서 이름·설명·키워드를 찾는다. 블록을 누르면 도움말을 볼 수 있고, 각 항목의 ‘설명’도 펼칠 수 있다. |
| 끌어 놓기가 어려움 | 숫자 칸·육각 조건 칸·조건 안쪽을 선택한 뒤 꾸러미의 ‘＋ 추가’를 사용한다. ‘점수 끝 선택’·‘시작 끝 선택’으로 넣을 묶음을 정할 수 있다. |
| 클릭만 했는데 블록이 떨어짐 | 누르기와 일정 거리 이상 끌기를 구분한다. 끄는 동안 연결 가능한 칸을 표시하며 숫자와 판단의 모양을 구분한다. |
| 숫자를 입력하는 중 | 음수·소수·지수 표기를 지원한다. 빈칸·문자·무한대와 조건 범위 오류를 표시한다. Enter 또는 포커스 이동으로 유효 입력을 확정하며, Esc로 입력을 취소한다. |
| 비슷한 규칙을 만들거나 일부를 지움 | ‘선택 복사’는 선택 블록과 내부를 복제한다. ‘선택 삭제’는 선택 블록과 내부를 지우되 뒤에 이어진 블록은 남긴다. 키보드 Enter/Space 선택, Delete/Backspace 삭제, Ctrl/Cmd+D 복사도 제공한다. |
| 복잡한 배치를 정리함 | ‘줄 맞추기’가 연결 관계를 유지하며 묶음을 세로로 정렬한다. 확대·축소와 스크롤을 사용할 수 있다. |
| 이미 채운 칸에 다른 블록을 넣음 | 기존 블록을 버리지 않고 조립소 아래에 따로 보관한다. 따로 둔 블록에는 ‘연결 전 · 실행 제외’를 표시한다. |
| 잘못 끌거나 지움 | Esc로 이동을 취소한다. 맞지 않는 칸이나 조립소 밖에 놓은 기존 블록은 원래 위치로 돌린다. 휴지통 삭제·예시 적용·초기 블록 복원은 되돌리기로 복구할 수 있다. |

값 블록을 넣을 칸을 선택하지 않고 추가하면 따로 보관된다. 쌓기 블록을 끌면 그 아래에 이어진 블록도 함께 이동하므로, 하나만 지우려면 ‘선택 삭제’를 쓴다. 따라 하기 모드는 블록 구조를 고정하고 고르는 칸만 변경한다.

## 블록 목록의 변화

| 학생이 표현할 내용 | 제공 블록 / 의미 |
|---|---|
| 10도 이하, 80 이상 | `le`, `ge`: 경계값을 포함하는 비교 |
| 정확히 같은 값, 다른 값 | `eq`, `neq`: 정확 비교. 센서·소수 값에는 구간 비교를 안내 |
| −10도부터 +10도까지 | `between`: 값, 최솟값, 최댓값. 양 끝 포함 |
| 조건 분기가 어떻게 실행되는가 | `true`, `false`: 항상 참·거짓인 조건값 |
| 둘 중 작은 값·큰 값 | `min`, `max`: 두 숫자 중 하나를 반환 |
| 점수가 너무 커지지 않게 하기 | `clamp`: 값, 최솟값, 최댓값으로 제한 |
| 방향에 따라 다른 점수 주기 | `tilt_signed`, `armang_signed`, `pvel_signed`, `avel_signed` |

기존 블록의 식·타입·슬롯 수·드롭다운 저장값은 유지한다. 새로운 방향 블록은 고급 그룹에 둔다. 팔 각도는 회전수를 보존하는 누적 값이며, 진자 직립 오차는 직립을 0으로 한 각도이다. 부호는 모델 좌표계 기준이며 모터 방향이나 화면 좌우로 단정하지 않는다.

## 단위와 숫자 조건

- 높이·진자 빠르기·팔 빠르기·모터 힘 지령은 `0~100` 값을 쓴다. 각도는 `deg`, 방향 있는 각속도는 `rad/s`이다.
- 속도 정규화 기준은 기존의 진자 25 rad/s, 팔 19.2 rad/s를 유지한다. 팔의 모델 종료 한계 약 19.1986 rad/s와 표시 기준을 구분한다. 표시값 100은 실물 안전 검증값이 아니다.
- 모터 힘은 지령의 크기이며 측정 토크·소비 전력이 아니다.
- 모든 블록에 `name`, `search`, `unit` 메타데이터와 구체적인 입력·출력·연결 예시 팁을 제공한다. 일부 값에는 `range`, 방향 값에는 `advanced`, 참·거짓에는 `constant`와 `literal`을 둔다.
- `PS.RUN_PARAMS`는 세대 4~80(정수), 정책 수 6~40(정수), 바꾸는 크기 1~30(실제 사용 값은 입력/100)를 정의한다. `PS.numericSpec(type, fields, slotIndex)`는 첫 슬롯의 조건 정보 또는 시험 시간 3~20초(정수)를 반환한다. UI와 규칙 점검에서 같은 정보를 사용할 수 있다.
- `between`·`clamp`에서 고정 최솟값이 최댓값보다 크면 규칙 점검에서 오류로 표시한다. 상태에 따라 경계가 바뀌면 안내하고 실행 중에도 순서를 검사한다. 자동으로 두 입력을 바꿔 쓰지 않는다.

## 예시 규칙

기존 예시를 유지하고 마지막에 세 예시를 추가했다. 구간 조건과 if/else, and/or와 경계 비교, 제곱 감점과 범위 제한을 각각 살펴본다. 설명에는 예상할 질문과 수치 예시를 포함하며 학습 성공을 보장하지 않는다.

## 오류와 안내

‘규칙 점검’ 패널은 실행을 막는 **수정 필요**와 학생이 판단할 **살펴보기**를 구분한다. 문제 목록을 펼쳐 항목을 누르면 해당 블록이나 칸으로 이동하고 강조한다. 전체 규칙에 관한 안내처럼 특정 위치가 없는 항목은 이동 버튼을 비활성화한다.

- 수정 필요: 비어 있는 조건 칸, 잘못된 연결, 유한하지 않은 숫자, 고정값의 0 나눗셈, 뒤집힌 고정 범위, 지나친 중첩, 범위를 벗어난 학습 조건, 지원하지 않는 실행 순서 등. 시작 전에 고쳐야 한다.
- 살펴보기: 서로 다른 단위, 음수를 빼는 감점, 항상 같은 조건·점수, 비어 있는 분기, 중복 학습 조건, 따로 놓인 블록 등. 실행 제외 블록의 입력 문제는 안내로 낮추며, 연결하면 다시 실행 오류로 검사한다.
- 예시 상태의 점수 비교: 매달림·회전 예시가 직립보다 좋은 점수를 받는지 보여 준다. 이 점검은 몇 가지 상태의 계산이며 진자 시뮬레이션이나 안정성 검증을 대신하지 않는다.
- 상태에 따라 바뀌는 나눗셈의 분모에는 별도 안내를 제공한다. 실행 중 분모가 0이 되면 오류를 전달하고 계산을 중단한다. 학생에게 0이 아닌 경우만 계산하는 조건이나 양수 하한을 쓰도록 설명한다.

학습·시험 중 범위 역전, 계산 결과 또는 누적 점수의 비유한 값처럼 실행 오류가 발생하면 계산을 중단하고 편집 잠금을 해제한다. 오류 메시지와 가능한 블록 위치를 보여 주며, 실패한 정책을 현재 결과로 계속 사용하지 않는다. 학습 시작 단계의 오류도 오류 콜백으로 전달해 화면이 실행 중 상태에 남지 않도록 처리한다.

## 저장 호환성

기존 블록 타입·슬롯·드롭다운 저장값은 유지한다. 새 보상 키 `blocks-v2:`는 표시 문장 대신 실행되는 보상 블록의 타입·순서·입력값·고르는 값·중첩 구조를 기록한다. 블록 ID, 화면 위치, 표시 이름, 실행 제외 블록은 보상 키에 포함하지 않으며 숫자값을 표시용으로 반올림하지 않는다. 앱의 정책 일치 검사에는 세대 수·정책 수·바꾸는 크기도 별도로 포함한다.

구형 문장 기반 `blocks:` 정책 키가 있는 수업 파일은 블록·진행 상태·실험 기록을 읽되 이전 정책을 적용하지 않는다. 화면에서 식별 방식 변경과 현재 규칙으로 다시 학습해야 함을 안내한다. 저장된 기록은 현재 실행 결과와 구분하며, 호환되는 새 정책도 불러온 뒤 시뮬레이션에서 다시 확인한다. 파일의 기본 구조와 모델·관측 규격 검사는 유지한다.

## 확인 범위

이번 변경은 **소스 검토만** 수행했다. 앱 실행, 자동 테스트, 시뮬레이션, 학습, 실물 시험은 실행하지 않았다. 실제 화면의 조작감·배치와 수업 흐름은 사용자가 확인할 항목이며, 이 문서의 동작 설명을 실행 검증 통과 기록으로 해석하지 않는다.
