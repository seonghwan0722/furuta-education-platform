# rev22 3D 모델로 PID·LQR·LMPC 재검증 (2026-11-27)

확인 범위: **PC 시뮬레이션만**. MATLAB 제어기 코드(`lm_design`, `lm_controller`, `sp_env2`)를 Python으로 옮겨 돌렸다.
rev22 실물, Pi, Simscape fixed MIL에서는 돌리지 않았다.

## 0. 요약

- zip에는 MuJoCo XML이나 질량 데이터가 없다. STEP·f3d·STL만 있다. 그래서 **STEP 형상에 밀도를 가정해서** 질량 특성을 직접 계산했다.
- rev22 진자는 rev11보다 7.3 g 무겁다(39.2 g). 대신 무게중심이 피벗에 더 가깝다(84.5 → 71.6 mm). 그래서 운동방정식 계수는 3~9%만 바뀐다. 결합항 γ가 +8.9%로 가장 많이 바뀐다.
- 세 제어기를 rev22 계수로 다시 설계했다. 레시피는 rev11과 같다. 새 LQR 이득은 K = [1.490 21.21 0.904 2.361]이다(rev11 [1.414 25.76 0.834 2.862]).
- rev22 공칭 조건(11/23 실측 마찰·관성)에서 세 제어기 모두 지연 10/15/20 ms에서 123/123을 통과했다. MuJoCo 고정 시작은 16/16이다.
- 하드웨어처럼 정지마찰, 영점 1° 오차, 진자 마찰을 넣은 조건에서는 셋이 갈린다.
  - **LMPC**: 43/43 (20 ms에서도 43/43)
  - **PID**: 40/43 (20 ms에서 21/43)
  - **LQR**: 엄격 기준 0/43. 넘어지지는 않지만 ±3° 진동 때문에 기준을 못 맞춘다. rev11 실물의 1 Hz 진동과 같은 현상이다.
- 20 ms 지연에서 rev22가 rev11보다 크게 좋아 보이는 데는 이유가 둘 있다.
  - 큰 쪽은 **가정 차이**다. 마찰을 11/23 실측값으로 바꿨고, γ에 ×0.8 보정을 하지 않았다.
  - 형상 효과는 작다. rev11과 같은 가정(식별 마찰 + γ×0.8)으로 맞추면 LQR은 38 → 89/123, LMPC는 66 → 110/123이다.

## 4. 결과 (rev11 vs rev22)

평가 조건은 기존 경량 배치(`sp_env2`)와 같다.
- Pi 관측: 12비트 진자, 0.01° 암, 30 ms 필터. 지령 1스텝 + 분수 지연, ±1.5 A, Kt 2.1 → 3.15 N·m
- 엄격 기준: 20 s 안에 도달, ±5°·±0.5 rad/s를 5 s 유지, 암 15·펜듈럼 25 rad/s 미만. 25 s 실행
- 각 칸 형식: **통과/전체 · 평균 도달 시간 · 포화율**. 포화율은 ±1.5 A에 붙은 주기의 비율이고, 거의 전부 스윙업 구간에서 나온다. 직립 구간 포화는 모든 칸에서 0%였다.
- rev11은 실물에 올린 설계(LQR rev11, PID r7, LMPC rev11c)를 rev11 식별 플랜트에서 돌렸다. rev22는 재설계한 것을 rev22 공칭 플랜트에서 돌렸다.

### 4-2. 플랜트 변경 (지연 10 ms, 고정 3 + 무작위 40 = 43개)

| 조건 | LQR rev11 → rev22 | PID rev11 → rev22 | LMPC rev11 → rev22 |
|---|---|---|---|
| γ ×0.8 | 43 → 43 (5.21 → 1.75 s) | **0** → 43 | 43 → 43 |
| γ ×1.2 | 43 → 43 | 7 → 43 | 43 → 43 |
| 쿨롱 ×0.5 | 40 → 43 | 23 → 43 | 41 → 43 |
| 쿨롱 ×1.25 | 43 → 43 | 1 → 43 | 43 → 43 |
| α ×0.85 | 43 → 43 | 0 → 43 | 43 → 43 |
| α ×1.15 | 43 → 43 | 43 → 43 | 43 → 43 |
| 마찰 세트 교환 ¹ | 43 → 43 | 1 → 43 | 43 → 43 |
| 하드웨어형 ² 10 ms | 0 → 0 (20 s 유지 43 → 43) | 0 → **40** (9.34 s) | 43 → **43** (3.28 → 1.68 s) |
| 하드웨어형 ² 20 ms (영점 −1°) | 0 → 0 (유지 0 → 43) | 0 → 21 (13.5 s) | 1 → **43** (2.05 s) |

1. rev11에는 11/23 실측 마찰을, rev22에는 rev11 식별 마찰(0.40/0.12)을 넣었다.
2. `job_rev11_lmpc_b` cond 2·3과 같다: 암 정지마찰 +50%, 진자 영점 오차 +1°(20 ms는 −1°), 진자 베어링 쿨롱 1e-3 N·m.

포화율은 rev22 전 조건에서 2.0~3.3%였다. rev11 PID는 실패 조건에서 34~50%까지 올라갔다.

- "20 s 유지"는 마지막 10 s 동안 |θ|<10°을 지킨 개수다.
- LQR이 하드웨어형 조건에서 0이 나오는 이유는 넘어져서가 아니다. ±3°, 약 1 Hz로 계속 흔들려서 ±0.5 rad/s 기준을 5 s 연속으로 못 맞춘다.
- 이 현상은 rev11 실물에서 본 진동과 같다. rev11c LMPC를 만든 이유도 이 진동이었다.

### 4-3. MuJoCo 고정 시작 16개 (fixed MIL 대신)

물리 엔진을 바꿔 같은 제어기를 다시 돌렸다. 플랜트는 MuJoCo RK4 2 ms이고 암 쿨롱은 tanh로 넣었다(`xcheck.MujocoPlant`).
시작점은 180°, ±175°, … 0°의 16개다.

| 제어기 | 지연 | rev11 | rev22 |
|---|---|---|---|
| LQR | 10 ms | 16/16 · 1.55 s · 2.0% | 16/16 · 1.04 s · 2.1% |
| LQR | 20 ms | 9/16 · 3.71 s · 15.4% | 16/16 · 1.14 s · 2.1% |
| PID | 10 ms | 14/16 · 7.19 s · 15.9% | 16/16 · 1.03 s · 2.0% |
| PID | 20 ms | 16/16 · 3.27 s · 4.1% | 16/16 · 1.14 s · 2.0% |
| LMPC | 10 ms | 16/16 · 1.62 s · 2.0% | 16/16 · 1.06 s · 2.0% |
| LMPC | 20 ms | 10/16 · 5.67 s · 14.7% | 16/16 · 1.14 s · 2.0% |

**fixed MIL(Simscape RMD 모델)은 돌리지 못했다.**
- MATLAB/Simulink가 필요하다.
- `lm_fixed_eval`은 모델 작업공간의 `plantCoefficients`가 기준 플랜트(α 0.05)와 같은지 assert한다. rev22로 돌리려면 그 계수부터 rev22로 바꿔야 한다.

### 4-4. 차이가 어디서 오는가: 가정을 rev11과 맞춘 재실행

rev22 형상에 rev11과 같은 가정을 넣고 다시 설계·평가했다. 경량 배치 123개, 각 칸은 지연 10 / 15 / 20 ms다.

| 가정 | LQR | PID | LMPC |
|---|---|---|---|
| rev11 (식별 마찰 + γ×0.8), 실물 설계 | 123 / 123 / 38 | 84 / 123 / 123 | 123 / 123 / 66 |
| rev22 + 식별 마찰 + **γ×0.8** | 123 / 123 / **89** | 123 / 123 / 85 | 123 / 123 / **110** |
| rev22 + 식별 마찰 + γ CAD | 123 / 123 / 123 | 123 / 123 / 123 | 123 / 123 / 123 |
| rev22 + 11/23 마찰 + γ CAD (공칭) | 123 / 123 / 123 | 123 / 123 / 123 | 123 / 123 / 123 |

- 20 ms 지연 성능을 가장 크게 바꾸는 것은 **γ를 CAD 그대로 믿느냐**다. rev11 때도 결합항이 결과를 가장 크게 바꿨다.
- 같은 가정(γ×0.8)에서도 rev22가 rev11보다 낫다: LQR 38 → 89, LMPC 66 → 110. 다만 형상 덕분인 개선은 이 정도다.
- rev11 PID r7은 시뮬에서 약하지만 실물에서는 2/2 통과했다(도달 14.8 s). 그 이유는 다음과 같다.
  - r7은 관측기와 에너지 식에 옛 기준 플랜트(α 0.05, δ 0.0169)를 쓴다.
  - 그래서 스윙업 에너지 목표가 실제와 다르고 도달이 느리다.
  - 실물의 긴 도달 시간과 방향이 맞는다.
  - rev22 PID는 rev22 모델로 관측기와 에너지 식을 다시 맞췄다.

## 5. 실물로 가기 전에 할 것

1. **진자 질량을 저울로 잰다.** 볼·로드·축을 합쳐 39.2 g 근처인지 확인한다. 다르면 밀도 가정을 고치고 `code/rev22_model.py` → `coeffs.py`를 다시 돌린다.
2. **진자 주기를 잰다.** 작은 진폭으로 흔들어 0.70 s인지 본다. β₂/δ를 확인하는 가장 싼 방법이다.
3. **γ는 실물 로그로 다시 맞춘다.** rev11처럼 ×0.8이면 20 ms 지연에서 LQR 89/123, LMPC 110/123 수준으로 내려간다. 그때는 LMPC가 가장 안전하다.
4. **진자 영점(thOffsetDeg)을 다시 잰다.** rev11의 2.77°는 rev22에 쓸 수 없다.
5. Pi export는 아직 하지 않았다. `matlab/job_rev22_classic.m` 맨 아래 주석에 export 줄이 있다. 영점을 넣고 주석을 풀면 된다.

시험 순서는 기존 계획(`HARDWARE_TEST_PID_LQR.md`)과 같게 권장한다: 직립 유지 전용 → 스윙업.
하드웨어형 조건 결과로 보면 rev22에서는 **LMPC → PID → LQR** 순서로 기대치가 높다.
